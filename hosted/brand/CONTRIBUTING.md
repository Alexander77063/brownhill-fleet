# Brand assets

`icon.svg` is the single source of truth for the Brownhill Fleet mark. Nothing
else is edited by hand: `pnpm build:icons` renders it into every icon file the
app actually serves.

## Changing the mark

1. Edit `hosted/brand/icon.svg`.
   - Keep the `viewBox` at `0 0 512 512`.
   - Keep the background as a single
     `<rect width="512" height="512" rx="112" .../>` element. The maskable
     icons are rebuilt from that element — the script replaces it with a
     full-bleed square and scales the mark to 80% — so if it is renamed or
     removed, `pnpm build:icons` fails loudly rather than emitting a broken
     icon.
2. Run `pnpm build:icons` from the repository root.
3. Commit the regenerated files **together with** the SVG change:

   ```
   public/icon.svg
   public/favicon-16.png
   public/favicon-32.png
   public/favicon.ico
   public/icons/icon-192.png
   public/icons/icon-512.png
   public/icons/apple-touch-icon.png
   public/icons/maskable-192.png
   public/icons/maskable-512.png
   ```

## Why these paths

The previous version of this pipeline rendered into `hosted/static/`. That
directory is in `.gitignore` and nothing copies it into a build, so the icons
it produced were never committed and never deployed — while the icons the
browser loads (`public/favicon-32.png`, `public/icons/*.png`, referenced from
`src/app/layout.tsx` and the web app manifest) could only be regenerated by
hand. The output went nowhere and the input did not match what was served.

`public/` is tracked because it is served. The script writes there now, and
`public/manifest.webmanifest` is no longer a file at all: it is generated by
`src/app/manifest.webmanifest/route.ts` from `deploymentBrand()`, so the
install prompt on the operator's phone carries the same product name as the
window title.

## Checking the result

```bash
pnpm build:icons
```

The script prints every file it writes. To eyeball the result, open
`public/icons/icon-512.png` (the plain mark) and
`public/icons/maskable-512.png` (the same mark at 80% on a full-bleed
background, safe to crop to a circle).
